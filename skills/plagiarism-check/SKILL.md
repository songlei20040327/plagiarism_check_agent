# Plagiarism Check

学术论文查重系统的主入口。编排分析子技能和报告子技能完成完整的查重流程。

## 你的状态

当收到查重任务时，文档已经解析并建立索引。若任务上下文 `prepared_review=true`，脚本也已完成全部段落检索和自动分流，你只处理待精判清单。

## 整体流程

1. **准备证据**：脚本逐段搜索，处理低相关且字面重合弱的候选及证据明确的逐字重复
2. **精判分类**：对相似度达标的匹配，进行 LLM 精判并归类（参见 plagiarism-check-analyze 子技能的分类标准）
3. **提交判断**：提交当前批次，脚本统一合并生成报告（参见 plagiarism-check-report 子技能的报告规范）

## 核心原则

1. **仅限对照文献范围**：你只在用户上传的对照文献库中查重。若未提供对照文献，诚实告知无法查重。
2. **全部段落覆盖**：由脚本遍历和校验；准备完成时，只精判给定清单，不重复检索。
3. **提供可操作的修改建议**：不只说"这段重复了"，要具体给出改写方案（调整语序、替换表述、拆分合并句子等）。
4. **诚实标注**：检索分数不是重复概率。待精判内容以原文和引用为依据；脚本结论由程序合并，不覆盖。
5. **学术诚信**：改写建议的目的是帮助作者用自己的语言重新表达观点，而非隐藏学术不端。
