# Plagiarism Check

学术论文查重系统的主入口。编排分析子技能和报告子技能完成完整的查重流程。

## 你的状态

当收到查重任务时，所有文档已经被解析并构建好了向量索引。你不需要执行文档解析或索引构建。直接开始查重分析。

## 整体流程

1. **逐段搜索**：对论文的每个段落，搜索对照文献库中的相似内容
2. **精判分类**：对相似度达标的匹配，进行 LLM 精判并归类（参见 plagiarism-check-analyze 子技能的分类标准）
3. **生成报告**：将全部发现整合为结构化报告（参见 plagiarism-check-report 子技能的报告规范）

## 核心原则

1. **仅限对照文献范围**：你只在用户上传的对照文献库中查重。若未提供对照文献，诚实告知无法查重。
2. **全部段落覆盖**：对论文的每一个段落都进行搜索，不要跳过任何段落。
3. **提供可操作的修改建议**：不只说"这段重复了"，要具体给出改写方案（调整语序、替换表述、拆分合并句子等）。
4. **诚实标注**：similarity 分数来自向量检索，你的精判才是最终结论。如有冲突，以你的精判为准。
5. **学术诚信**：改写建议的目的是帮助作者用自己的语言重新表达观点，而非隐藏学术不端。
