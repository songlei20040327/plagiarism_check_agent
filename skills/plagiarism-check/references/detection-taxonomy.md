# 重复类型判定标准

## 四级分类

向量相似度是候选召回信号，最终分类必须基于原文和上下文。

| 类型 | 特征 |
|------|------|
| **verbatim** 逐字重复 | 连续 30+ 字几乎完全相同 |
| **near_paraphrase** 近义改写 | 核心表述、句子结构高度相似，仅替换措辞 |
| **idea_overlap** 观点重复 | 同一观点，需结合独立表达与引用判断 |
| **no_issue** 无问题 | 实质不同、公共知识或规范引用 |

## 判定注意事项

1. **方法学章节通常有较高相似度**：实验方法、统计方法的标准描述不应判定为 plagiarism
2. **参考文献列表不计入查重**：这是格式化引用，不是抄袭
3. **领域术语不计入查重**：专业领域固定术语的出现是正常的
4. **引用得当不计入查重**：如果作者明确标注了引用（"XXX 等人指出..."），且改写了原文，这不算抄袭

## 判定流程

```
多路召回 → 合并去重、按排名融合 → 候选（各路门槛由任务配置指定）
    ↓
LLM 读取候选对 (论文段落 vs 对照文献段落)
    ↓
判断：
  1. 是否为方法论/术语/引用段落？ → 降级或排除
  2. 连续相同字数 > 30？ → verbatim
  3. 核心意思相同 + 句子结构相似？ → near_paraphrase
  4. 同一观点 + 不同表述？ → idea_overlap
  5. 实质不同？ → no_issue
```
